
# Global Cost of a Healthy Diet Analysis 🌍🥗

## Overview
This project analyzes the cost of a healthy diet across different countries
and regions using real-world data.

## Dataset
- Country-level healthy diet cost data
- Costs are reported in PPP USD

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Insights
- The cost of a healthy diet varies significantly across regions.
- Higher food component costs lead to higher healthy diet costs.
- Fruit and vegetable prices play a major role in diet affordability.

## Conclusion
The analysis highlights global disparities in access to affordable healthy diets
and provides insights relevant to policymakers and researchers.
